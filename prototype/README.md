# DoDo 待办应用 · HTML 设计原型

双击 `index.html` 即可在浏览器中打开(无需任何依赖,单文件自包含)。

## 可体验的交互

- 侧边栏切换视图:**今天 / 收件箱 / 计划 / 看板 / 日历 / 全部 / 已完成**,以及清单(工作/生活/学习)和标签
- 勾选任务完成(带划线动画)、hover 任务行出现「移到明天 / 删除」、删除后可**撤销**
- 点击任务行 / 看板卡片 → 右侧滑出**详情面板**:改标题、备注、子任务、清单、日期、提醒、重复、优先级、标签
- 底部快速添加条支持**自然语言片段**:`明天 14:00 写周报 #工作 !高 @重点`(输入时实时显示解析 chips,回车添加)
- 看板视图支持**拖拽卡片**更换优先级
- 右上角月亮/太阳按钮切换**明暗主题**(会记住选择)
- 标题栏搜索框实时过滤(`/` 聚焦,`N` 聚焦添加条,`Esc` 关闭面板)

## 说明

示例数据基于打开当天的日期动态生成(含逾期、今天、未来 7 天、已完成),每次打开都是"今天"。
此原型仅用于美观与交互确认;确认后按《UI 设计文档》与《需求文档》开发 Tauri 桌面应用,前端代码将由本原型迁移。
