# DoDo · Windows 桌面待办应用

> 快速捕捉、清晰聚焦、赏心悦目 —— 本地优先的 Windows 待办工具

DoDo 是一款面向个人用户的 Windows 桌面待办事项应用：**Tauri 2 + 原生 HTML/CSS/JS**（无框架、无构建打包步骤），数据存本地 SQLite，无需注册登录，完全离线可用。

## 功能亮点

- **自然语言快速添加**：`明天 14:00 写周报 #工作 !高` 一句输入，自动解析日期/时刻/清单/优先级/标签/重复，输入时实时显示解析预览，内置 20 组解析自测用例
- **重复任务「完成即归档 + 惰性复活」**：勾选后当天保持完成状态，不立刻弹出新任务；下一轮到期日在当天自动恢复为待办，支持频率 + 间隔 + 周几多选 + 月几号（小月钳制）+ 结束条件
- **七类视图**：今天 / 收件箱 / 计划（未来 7 天）/ 看板（按优先级拖拽）/ 日历 / 全部 / 已完成，外加清单与标签视图
- **任务详情**：子任务、备注、清单、日期（迷你月历）、提醒时刻、重复规则编辑器、优先级、标签
- **桌面集成**：系统托盘（关闭最小化到托盘）、全局快捷键 `Ctrl+Shift+Space` 呼出速记、Windows 系统通知、开机自启动
- **数据自主**：本地 SQLite 持久化（事务化增量写入）、每日自动备份（保留最近 7 份）、自定义存储位置与迁移、导出 JSON
- **明暗双主题**、一周起始日 / 12/24 小时制、键盘友好（`N` 速记、`/` 搜索、`Esc` 逐层关闭）

## 快速开始

### 环境要求

- [Node.js](https://nodejs.org/) 18+
- [Rust](https://rustup.rs/)（stable 工具链）
- Windows 10 1903+ / Windows 11（WebView2 系统自带，缺失时安装器会自动下载）

### 开发

```bash
npm install
npm run dev        # tauri dev：改 ui/ 热更新，改 Rust 自动重编译重启
```

### 自测

```bash
node scripts/selftest-harness.js   # 20 组解析 / 重复任务用例，免浏览器，退出码 0 = 全过
```

也可在浏览器打开 `ui/index.html?selftest=1` 查看结果。

### 打包

```bash
npm run build      # 产出 NSIS 安装包：src-tauri/target/release/bundle/nsis/
```

## 目录结构

```
├─ ui/                  正式前端（index.html + app.js + styles.css，无构建直接加载）
├─ src-tauri/           Tauri 2 后端（托盘 / 全局快捷键 / SQLite 迁移 / 通知 / 备份 / 事务批量写入）
└─ scripts/             selftest 沙箱跑测
```
